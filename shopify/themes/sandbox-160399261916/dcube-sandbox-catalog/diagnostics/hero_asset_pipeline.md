## SPRINT 2 — IMAGE RE-GENERATION PIPELINE

### Tool: Sharp (already available at `apps/image-pipeline/node_modules/sharp`)

### Desired composition parameters:
- Candle: bottom-right quadrant, ≤35% of frame width
- Left 55%: clean background (ocean, sky, sand — no competing objects)
- Height: portrait 1200×1600px

### Sharp recompose script (workaround — NOT full fix):
```javascript
// apps/image-pipeline/scripts/recompose-mobile-heroes.mjs
import sharp from 'sharp';
import { resolve } from 'path';

const ASSETS = resolve('D:/onedrive/Desktop/becandle/shopify/themes/sandbox-160399261916/assets');
const BRAND_MIST = { r: 230, g: 225, b: 235 };

async function recompose(slug, cropLeft, cropWidth) {
  const input = resolve(ASSETS, `${slug}__mobile.webp`);
  const output = resolve(ASSETS, `${slug}__mobile.webp`);  // overwrite
  await sharp(input)
    .extract({ left: cropLeft, top: 0, width: cropWidth, height: 1600 })
    .resize(1200, 1600, { fit: 'fill' })
    .webp({ quality: 87, effort: 5 })
    .toFile(output);
  console.log(`Recomposed: ${slug} (crop from x=${cropLeft}, w=${cropWidth})`);
}

// Cut leftmost citrus/decorations; shifts candle ~15-20% rightward
await recompose('slide-1__brand-statement', 240, 960);   // cut 240px left (orange)
await recompose('slide-2__coastal-collection', 300, 900); // cut 300px left (orange)
await recompose('slide-4__gifting-premium', 240, 960);   // cut 240px left (orange/starfish)
// Slide 3 (evening mood): SKIP — dark background handles contrast correctly
```

**Limitation:** Candle remains somewhat centered. Full fix requires AI image re-generation with wider field of view prompt.
