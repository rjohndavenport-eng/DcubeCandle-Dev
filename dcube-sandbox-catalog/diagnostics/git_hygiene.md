## Deployment Paths

### Path A — CLI-first (CURRENT — recommended)
```
local edit → git commit → .\scripts\shopify_theme_sync.ps1 push
```
Fast. No CI. Full manual control. Use this now.

### Path B — GitHub Actions (FUTURE — optional)
```
push to sandbox/* branch → .github/workflows/shopify-sandbox-deploy.yml → shopify theme push
```
Requires: `SHOPIFY_CLI_THEME_TOKEN` secret added at:
GitHub → repo Settings → Secrets and variables → Actions → New repository secret

### Path C — Shopify GitHub Integration (NOT recommended)
Shopify's native GitHub sync is limited to published themes on specific plans.
For sandbox/unpublished themes, CLI push (Path A) is the only reliable option.

## Rebase Recovery

```bash
git status                 # check current state
git rebase --continue      # if all conflicts resolved
git rebase --abort         # cancel — returns to pre-rebase state
```
