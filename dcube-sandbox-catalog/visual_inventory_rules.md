# VISUAL PRESERVATION & EDIT READINESS RULES

## 1. CLASSIFICATION TAGS
- `[PROTECTED]`: Logos, brand marks, product labels.
- `[EDITABLE]`: Backgrounds, atmospheric overlays, lifestyle depth.
- `[RAW]`: Unprocessed camera outputs.

## 2. LOGO/LABEL POLICY
- **RULE 01:** No generative repainting of text.
- **RULE 02:** 400% zoom integrity check required.
- **RULE 03:** Labels must remain rectilinear; no warping.

## 3. FILENAME NORMALIZATION
- Format: `dcube_[scent]_[angle]_[version].[ext]`
- Example: `dcube_lavender_hero_v1.webp`

## 4. DEDUPE STRATEGY
- SHA-256 hash comparison required for all `/assets/` downloads.
